# Examples: one study, end to end

Real, signed Lake objects, generated by `pnpm examples` from the reference code. Every signature verifies (`packages/core/src/examples.test.ts`). Synthetic, sandbox domains only. Envelopes expire five minutes after they were made; verify them with the clock set to their `iat`.

| File | What it is |
|---|---|
| [`visitor-card.json`](visitor-card.json) | A visitor agent's signed A2A Agent Card with the Lake extension. |
| [`house-card.json`](house-card.json) | A hosted house's signed card. Its card lives next to its endpoint: /t/stan/.well-known/agent-card.json. |
| [`study.json`](study.json) | A declarative study. Its id is urn:lake:study: + the digest of its canonical JSON. |
| [`ethics-approval.json`](ethics-approval.json) | An ethics approval (VC-JOSE) for this study and these fields, with its issuer's card. Counts only if the owner trusts ethics.example. |
| [`study-certificate.json`](study-certificate.json) | An auditor's certificate for the study. Without one from a trusted auditor, no house runs it. |
| [`1-offer.json`](1-offer.json) | Step 1. The visitor knocks: an A2A data part with its card and a signed envelope carrying the offer, the study and both credentials. |
| [`2-counter.json`](2-counter.json) | Step 2. A house counters, signed, and says it bargains as a bloc. |
| [`3-bloc.json`](3-bloc.json) | Step 3. The bloc rule (SPEC §5.3), applied to two signed counters: $2 becomes $5 and postcode is dropped. |
| [`4-join.json`](4-join.json) | Step 4. The house joins: a grant under the owner's standing rule, and an ODRL Agreement it has signed. |
| [`grant.json`](grant.json) | The grant, decoded: a Solid Access Grant (Inrupt format, GConsent): the owner (id) gives the visitor (isProvidedTo) read access to these data, for this purpose (a DPV term), with the Lake terms alongside: which offer and study, single use, which rule allowed it. |
| [`status-list.json`](status-list.json) | A house's revocation list (W3C Bitstring Status List), served at /status/revocation: 131,072 bits, gzipped; a set bit is a key taken back or used up. The grant above names bit 48213 (not set). Anyone can check a key without the house learning which. |
| [`count-open.json`](count-open.json) | Before any house answers, the visitor opens one count at the Leader teller, naming the Helper; the Leader sets it up with the Helper and a key only the two of them hold (IETF DAP; SPEC §11.5). |
| [`5-compute.json`](5-compute.json) | Step 5. The visitor countersigns the agreement and asks the house to run the study inside its pod, naming the count. |
| [`count-report.json`](count-report.json) | Step 6a. What the Leader gets from the house: one share of its answer and the public part of its proof. The Helper gets the other share. Neither share says anything on its own. |
| [`6-counted.json`](6-counted.json) | Step 6. The house tells the visitor it sent its two shares. Nothing about its owner is in this message. |
| [`count-share.json`](count-share.json) | Each teller publishes one aggregate share, once, after both have checked every answer's proof. The Leader's share alone says nothing; added to the Helper's it gives the exact table. |
| [`intent-mandate.json`](intent-mandate.json) | AP2 Intent Mandate, signed by a human at the visitor's organisation: this study, $5,000 at most. |
| [`payment-mandate.json`](payment-mandate.json) | AP2 Payment Mandate, signed by the agent under the Intent Mandate. |
| [`7-receipt.json`](7-receipt.json) | Step 7. The visitor delivers the payments agent's receipt; the house files it in /receipts/. |
| [`events.json`](events.json) | Events as a node streams them: ids, kinds and counts, never record contents. |

Also at https://lake.doneinfifty.com/examples/v0/<file>.
