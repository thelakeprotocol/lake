# Lake extension `v0`

<p class="lead">This page is the identifier of the Lake extension to A2A Agent Cards: <code>https://lake.doneinfifty.com/ext/lake/v0</code>.</p>

An agent card that carries this URI in `capabilities.extensions` is a Lake card. Its `params` hold the Lake profile: `role`, `webId`, `ownerDomain`, `publicJwk`, `tags`, `lakeVersion`. The extension is marked `required`, so A2A clients declare it in the `A2A-Extensions` header.

- Specification: [SPEC §2.1](/docs/spec#_2-1-the-lake-extension)
- JSON Schema of the params: [/schemas/v0/lake-profile.json](/schemas/v0/lake-profile.json)
- For agents: [/docs/agents](/docs/agents)
