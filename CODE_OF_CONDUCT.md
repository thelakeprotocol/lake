# Code of conduct

The Lake adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Short version: be blunt about ideas, kind to people. Argue with the design, not the person. No harassment, no discrimination, no doxxing. That last one matters double in a project about personal data.

To report a problem, contact the maintainers privately through the [thelakeprotocol GitHub organisation](https://github.com/thelakeprotocol). Reports are kept confidential.
